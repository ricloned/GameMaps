# GameMaps — карта в стиле GTA

Android-приложение: обычная карта с GPS, поиском, магазинами и маршрутами, но оформленная как карта/радар из игр.

## Что умеет

- **15 стилей + 1 секретный**, у каждого свои цвета карты, игровые шрифты, значки, HUD и эффекты:
  - GTA: San Andreas, Los Santos HD (V), Neon Vice (Vice City)
  - Игры: Frontier (Red Dead), Cyber Grid (Watch Dogs), Chrome 2077 (Cyberpunk), Wasteland (Fallout Pip-Boy), Blockcraft (Minecraft), Pocket 1989 (Pokémon), Street Racer (NFS Most Wanted), Tactical Ops (Call of Duty)
  - Тематические: Grid Runner (синтвейв/Tron), The Code (Матрица), Treasure Map (пиратская карта), Blueprint (чертёж)
- **Все магазины и заведения** прямо на карте (из векторных тайлов OpenStreetMap), 16 категорий значков. Тап — адрес, часы работы, телефон.
- **Названия популярных мест**: музеи, театры, стадионы, храмы, парки, отели, вокзалы, метро. Номера домов при сильном приближении.
- **Круглый радар** с фоном и эффектами своего стиля, полный экран карты, GPS, компас, курс вверх.
- **Поиск**, «что рядом», маршруты (авто/вело/пешком), навигация с подсказками, **свои маршруты** из точек.
- **Игровой слой**: деньги за пройденные метры, звёзды розыска рядом с полицией, «MISSION PASSED» на финише, «WASTED» при потере GPS, уровни и опыт, шаги, достижения, след за игроком, название улицы как в San Andreas.
- **Пасхалки**: чит-коды из игр вводятся в строку поиска; есть секретный стиль.

## Как собрать и поставить на телефон

1. Установи **Android Studio** (бесплатно): https://developer.android.com/studio
2. Распакуй архив, в Android Studio: **File → Open** → выбери папку `GameMaps`.
3. Подожди, пока Gradle скачает зависимости (первый раз 3–10 минут, нужен интернет). Если Studio предложит обновить Gradle/AGP — можно согласиться.
4. На телефоне включи **режим разработчика** (Настройки → О телефоне → 7 раз тапнуть «Номер сборки») и **Отладку по USB**.
5. Подключи телефон кабелем, выбери его сверху и нажми зелёный **Run ▶**.

Либо собери файл APK: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**, затем перекинь `app/build/outputs/apk/debug/app-debug.apk` на телефон и установи.

## Управление

- **☰** — меню паузы (стиль, места, маршруты, настройки)
- **Радар / Карта** — переключить круглый радар и полноэкранную карту
- **◎** — вернуться к своей позиции
- **Маршрут** — редактор своего маршрута
- **Долгое нажатие** по карте — поставить метку и проложить туда маршрут

## Структура

```
app/src/main/java/com/radarmap/app/
  AppViewModel.kt        логика: GPS, места, поиск, маршруты, навигация
  MainActivity.kt
  style/GameStyles.kt    5 игровых стилей (цвета и шрифты)
  style/MapStyleJson.kt  генерация стиля векторной карты
  map/                   MapLibre, значки, GeoJSON
  net/Api.kt             Photon, Overpass, OSRM
  location/              GPS + компас
  ui/                    экраны: HUD, радар, поиск, меню паузы
```

## Сборка через GitHub Actions (без Android Studio)

1. Создай репозиторий на GitHub и запушь в него содержимое папки `GameMaps` (папка `.github` должна оказаться в корне репозитория).
2. Открой вкладку **Actions** — сборка «Build APK» запустится сама (или нажми **Run workflow**).
3. Через 5–10 минут открой завершённый запуск → внизу раздел **Artifacts** → скачай **GameMaps-apk**.
4. Внутри два файла: `app-debug.apk` и `app-release.apk` — любой можно поставить на телефон.
