# Radar Map — карта в стиле GTA

Android-приложение: обычная карта с GPS, поиском, магазинами и маршрутами, но оформленная как карта/радар из игр.

## Что умеет

- **5 стилей** (меняются в меню на лету): San Andreas (ретро 2004), Modern HD (GTA V), Neon Vice (Vice City), Frontier (Red Dead), Cyber Grid (Watch Dogs). Меняется всё: цвета карты, дороги, вода, шрифты, значки мест, стрелка игрока, меню.
- **Два режима**: полноэкранная карта и **круглый радар** с кольцом, маркером «N» и полосками скорости/GPS (как здоровье и броня). Круглый радар — заготовка под часы.
- **GPS**: своя позиция стрелкой, компас, «курс вверх», 3D-наклон, следование за мной.
- **Все магазины и заведения** из OpenStreetMap значками-«блипами» (15 категорий: продукты, ТЦ, одежда, электроника, еда, кафе, бары, заправки, автосервис, аптеки, больницы, банки, полиция, спортзалы, прочие). Без отзывов и рейтингов. Тап по значку — карточка: адрес, часы работы, телефон.
- **Поиск** адресов и мест + кнопки «что рядом» по категориям.
- **Маршрут до места** (авто / вело / пешком) и **навигация** с подсказками поворотов, расстоянием, временем прибытия и автоматическим перестроением, если свернул.
- **Свои маршруты**: ставишь точки тапами по карте, приложение прокладывает путь через все точки по дорогам, можно сохранить, показать и запустить потом.
- **Название улицы всплывает** при въезде, как районы в San Andreas.
- Без аккаунтов, без ключей API, всё бесплатно (OpenStreetMap, OpenFreeMap, Photon, Overpass, OSRM).

## Как собрать и поставить на телефон

1. Установи **Android Studio** (бесплатно): https://developer.android.com/studio
2. Распакуй архив, в Android Studio: **File → Open** → выбери папку `RadarMap`.
3. Подожди, пока Gradle скачает зависимости (первый раз 3–10 минут, нужен интернет). Если Studio предложит обновить Gradle/AGP — можно согласиться.
4. На телефоне включи **режим разработчика** (Настройки → О телефоне → 7 раз тапнуть «Номер сборки») и **Отладку по USB**.
5. Подключи телефон кабелем, выбери его сверху и нажми зелёный **Run ▶**.

Либо собери файл APK: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**, затем перекинь `app/build/outputs/apk/debug/app-debug.apk` на телефон и установи.

## Управление

- **☰** — меню паузы (стиль, места, маршруты, настройки)
- **Радар / Карта** — переключить круглый радар и полноэкранную карту
- **◎** — вернуться к своей позиции
- **Маршрут** — редактор своего маршрута
- **Долгое нажатие** по карте — поставить метку и проложить туда маршрут

## Структура

```
app/src/main/java/com/radarmap/app/
  AppViewModel.kt        логика: GPS, места, поиск, маршруты, навигация
  MainActivity.kt
  style/GameStyles.kt    5 игровых стилей (цвета и шрифты)
  style/MapStyleJson.kt  генерация стиля векторной карты
  map/                   MapLibre, значки, GeoJSON
  net/Api.kt             Photon, Overpass, OSRM
  location/              GPS + компас
  ui/                    экраны: HUD, радар, поиск, меню паузы
```

## Сборка через GitHub Actions (без Android Studio)

1. Создай репозиторий на GitHub и запушь в него содержимое папки `RadarMap` (папка `.github` должна оказаться в корне репозитория).
2. Открой вкладку **Actions** — сборка «Build APK» запустится сама (или нажми **Run workflow**).
3. Через 5–10 минут открой завершённый запуск → внизу раздел **Artifacts** → скачай **RadarMap-apk**.
4. Внутри два файла: `app-debug.apk` и `app-release.apk` — любой можно поставить на телефон.
